# AI Alignment Skill

A simple but powerful skill that ensures alignment when using frontier AI models like Astra and Fable. 
Recommended for use in any project. 
You can never be too careful. 

## Contents

- `SKILL.md` contains the skill metadata and instructions.
- `examples/example-output.md` shows an example of the skill in action.

## Installation

Copy this directory into your Claude or Codex skills directory, then invoke it as `$ai-alignment-skill` or allow the AI to select it automatically when relevant.
